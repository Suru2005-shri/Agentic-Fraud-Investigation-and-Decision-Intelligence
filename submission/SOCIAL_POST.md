# Social post

Built **ARGUS**, an agentic fraud-investigation system for the TigerGraph HHG challenge.

Instead of stopping at a fraud score, ARGUS:

→ investigates transaction history
→ traverses connected cards, devices and cases
→ retrieves prior investigations as memory
→ detects uncertainty and requests more evidence
→ updates its recommendation after evidence arrives
→ applies policy + approval controls
→ records the complete case for future investigations

The benchmark output includes an internal investigation record, evidence trail, next-best actions before/after evidence, approval routing and SAR decision support.

The production graph design uses TigerGraph with Customer, Card, Transaction, DeviceProfile, BillingRegion, EmailDomain and Case entities.
